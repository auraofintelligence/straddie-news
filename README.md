A static strategic-research dashboard for exploring a mixed-media local news outlet on
Minjerribah / North Stradbroke Island.

The page maps possible stakeholders, content programming, funding pathways, community pulse,
integrity questions and staged delivery. It is a proposal and onboarding aid, not an operating
newsroom, current news feed or statement that any named organisation has joined.

## What is here

- `index.html` contains the complete research dashboard.
- `assets/` contains the local page assets.
- `LICENSE` records the reuse conditions.

## Use locally

Open `index.html` in a browser. The current version has no backend, account system, live publishing
pipeline or verified contact database.

Before turning the proposal into a service, confirm editorial responsibility, cultural review,
source and correction standards, consent, privacy, defamation risk, accessibility, funding and a
clear separation between reporting, community notices and sponsored material.
